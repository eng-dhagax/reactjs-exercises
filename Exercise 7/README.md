# Exercise 7 – Mouse Position Tracker

This exercise is a React.js application that tracks the user's mouse position and displays the current X and Y coordinates on the screen.

## 📌 Exercise Overview

The application uses React `useState` and `useEffect` to listen for mouse movement and update the displayed coordinates.

The mouse position is stored as an object containing:

- `x` – Horizontal mouse position
- `y` – Vertical mouse position

## 🛠️ Technologies Used

- React.js
- JavaScript (JSX)
- React `useState`
- React `useEffect`
- Browser Mouse Events
- Vite

## ✨ Features

### Mouse Position Tracking

Whenever the mouse moves across the browser window, the application updates the coordinates.
