# Exercise 11 – Login Form

This exercise is a React.js login form that demonstrates how to manage form inputs and login state using React `useState`.

## 🎯 Objective

The goal of this exercise is to practice:

- Managing form inputs with `useState`
- Creating controlled inputs
- Handling form submission
- Preventing the default form behavior
- Managing login state
- Using conditional rendering
- Implementing a simple logout function

## 🔐 Login Form

The application provides two input fields:

- Username
- Password

The user can enter their information and submit the form using the **Login** button.
