# Exercise 21 – Student Dashboard with React and Tailwind CSS

## 🎯 Objective

The goal of this exercise is to build a modern **Student Dashboard** using React and Tailwind CSS.

The dashboard is divided into reusable components for the header, statistics, course progress, upcoming assignments, and announcements.

---

## 🚀 Features

- Modern student dashboard layout.
- Welcome header with notification indicator.
- Student profile avatar.
- Statistics cards.
- Course progress tracking.
- Dynamic course progress bars.
- Upcoming assignments section.
- Assignment status indicators.
- Announcements section.
- Reusable React components.
- Dynamic data rendering using `.map()`.
- Responsive grid-based layout.
- Tailwind CSS styling.
- Clean cards with rounded corners and shadows.

---

## 🧠 What I Learned

In this exercise, I learned:

- How to build a dashboard using reusable React components.
- How to divide a UI into smaller components.
- How to render arrays of data using `.map()`.
- How to use unique `key` values when rendering lists.
- How to create dynamic progress bars.
- How to apply dynamic CSS classes based on data.
- How to use Tailwind CSS utility classes.
- How to create layouts using CSS Grid.
- How to use `col-span-2` and `col-span-1`.
- How to organize a complete dashboard interface.
