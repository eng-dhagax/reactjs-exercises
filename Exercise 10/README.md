# Exercise 10 – User List

This exercise focuses on rendering a list of users in React using props, the `map()` method, and conditional rendering.

## 🎯 Objective

The goal of this exercise is to practice:

- Passing an array through React props
- Rendering lists using `map()`
- Using a unique `key` for list items
- Displaying dynamic user information
- Using conditional rendering
- Handling an empty users list
