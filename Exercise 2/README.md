# Exercise 2 – React Blog Components

This exercise focuses on building a simple blog structure using reusable React components.

## 🎯 Objective

The goal of this exercise is to practice:

- Creating React functional components
- Splitting a UI into smaller components
- Importing and exporting components
- Composing multiple components together
- Rendering components inside other components

## 🧩 Components

The project is structured using the following components:

- **App** – The main component that renders the `Blog` component.
- **Blog** – Combines the `Header`, `Post`, and `Footer` components.
- **Header** – Represents the blog header section.
- **Post** – Displays the blog post content.
- **Footer** – Represents the footer section.
