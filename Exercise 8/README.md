# Exercise 8 – Countdown Timer

This exercise is a React.js Countdown Timer that allows the user to set a time in seconds and control the countdown using Start, Stop, and Reset buttons.

## 📌 Exercise Overview

The application uses React state and effects to create a functional countdown timer.

The user can:

- Set the countdown time in seconds
- Start the timer
- Stop the timer
- Reset the timer to the selected time
- View the remaining time in seconds

## 🛠️ Technologies Used

- React.js
- JavaScript (JSX)
- React `useState`
- React `useEffect`
- `setInterval`
- `clearInterval`
- Vite
