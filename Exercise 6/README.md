# Exercise 6 – Dynamic Document Title with useEffect

This exercise is a React.js application that demonstrates how to use the `useEffect` Hook to dynamically update the browser document title based on user input.

## 📌 Exercise Overview

The application allows the user to:

- Enter their name
- Choose a greeting
- Dynamically update the browser tab title
- Display `Welcome!` when no name has been entered

## 🛠️ Technologies Used

- React.js
- JavaScript (JSX)
- React `useState`
- React `useEffect`
- Vite
