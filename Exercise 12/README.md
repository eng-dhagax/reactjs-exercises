# Exercise 12 – Counter

This exercise is a simple React.js counter application that uses `useState` to manage and update the counter value.

## 🎯 Objective

The goal of this exercise is to practice:

- Using React `useState`
- Updating state with button events
- Incrementing a counter
- Decrementing a counter
- Preventing the counter from going below zero
- Disabling a button based on state
